## Método Feynman
1. **Estudiar** un concepto y su implementación o caso.
2. **Explicar** el concepto sin consultar las notas, usando palabras sencillas.
3. **Detectar vacíos** mediante preguntas, errores y contraejemplos.
4. **Refinar** la explicación y comprobarla con un ejemplo nuevo.

**Criterio de dominio:** explicación verificable del estudiante, pregunta resuelta y aplicación independiente. No atribuir dominio sin evidencia.
